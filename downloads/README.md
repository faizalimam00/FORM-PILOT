# FormPilot for Chrome

[**Download FormPilot**](https://github.com/faizalimam00/FORM-PILOT/raw/refs/heads/main/downloads/formpilot-0.1.0-chrome.zip)

Extract the ZIP, open `chrome://extensions`, enable **Developer mode**, and choose **Load unpacked**. Select the extracted folder containing `manifest.json`.

[Installation and updates](../docs/installation.md) · [Privacy](../apps/website/src/pages/privacy.md) · [SHA-256 checksum](SHA256SUMS.txt)
