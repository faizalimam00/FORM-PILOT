## FormPilot

**Your details. Your device. Fill with a click. Stay in control.**

FormPilot is a local-first browser extension for repetitive forms. Save a reusable profile and fill matching fields with one click. Review uncertain matches, correct mappings and undo changes from the same toolbar popup. No account, backend or paid AI API is required.
